# EDH Primers

Complete EDH deck reports generated by **MTG Commander Builder** (Scryfall + EDHREC + Commander Spellbook).

🌐 **Online index** : https://chakkrachak.github.io/edh-primers/

Each primer contains: the commander sheet (verified Oracle text, SVG mana symbols), the chosen game plan with a secondary source, cards by EDHREC categories (synergy badges, explanations verified against the Oracle) and relevant combos filtered by color identity. **All content is in English** — Oracle texts and Commander Spellbook combo data are reproduced verbatim in their original language.

## Structure

```
├── index.html          ← landing page (commander cards)
├── css/
│   ├── theme.css       ← shared tokens (colors, shapes, typography)
│   ├── index.css       ← index styles
│   └── report.css      ← report styles (sheet, categories, combos)
└── content/            ← the reports (one HTML per commander)
```

The site is **100% static**: no inline CSS — the index loads `css/theme.css` + `css/index.css`, each report loads `css/theme.css` + `css/report.css`. Any new report generated by `report_gen.py` references these files automatically.
