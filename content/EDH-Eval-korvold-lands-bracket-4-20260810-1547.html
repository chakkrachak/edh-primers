1. Commander Sheet

Korvold, Fae-Cursed King — Bracket 4

Quick read

  • Core mechanic : Korvold turns every permanent you sacrifice into a +1/+1 counter AND a card — the classic Jund sac engine (Mayhem Devil pings, Viscera Seer/Ashnod's Altar fuel the loop).
  • Engine : sacrifice outlets + token/fetch fodder + draw-on-sac triggers (Korvold himself, Grim Haruspex-type effects).
  • Payoff : a giant flying Korvold that draws into more sac fodder every turn.
  • Draw into value : every sacrifice replaces itself — keep the engine fed and never run out of gas.

🎯 Lands Matter — 420 decks

📖 Game plan

  • Core mechanic : lands are the perfect sacrifice fodder — fetchlands crack themselves, Zuran Orb/Squandered Resources sac them for mana, and every land drop feeds Korvold's draw trigger (Landfall generators: Lotus Cobra, Tireless Provisioner).
  • Engine : landfall value (Tireless Provisioner, Lotus Cobra, Exploration) + land-sac outlets (Zuran Orb, Sylvan Safekeeper, Squandered Resources) + recursion (Aftermath Analyst, fetchlands).
  • Payoff : every land sacrificed draws a card and grows Korvold — the land base becomes a draw engine and the sac loops go infinite with Aftermath Analyst.

🏆 Win conditions

  • Draw velocity : each land sac replaces itself — keep the engine fed and out-draw everyone.
  • Infinite loops : Aftermath Analyst + sac outlet + fetchland = infinite landfall triggers and Korvold draws.
  • Commander damage : a 10/10+ flying Korvold closes in 2 hits after the land engine churns.

  • Core mechanic : Korvold's draw engine finds the pieces; the sac loops (Plunderer + Altar, Gravecrawler + outlet) generate infinite mana/draw/drain.

  • Payoff : infinite mana into a big X-spell, infinite drain, or a massive Korvold.

  • Infinite drain : add Zulaport Cutthroat/Mayhem Devil to the loop.

👑 Aristocrats — 868 decks

📖 Game plan

  • Core mechanic : the classic aristocrats engine — recursive creatures (Gravecrawler, Reassembling Skeleton, Squee) + sac outlets + drain payoffs (Zulaport Cutthroat, Blood Artist, Mayhem Devil).
  • Engine : infinite or near-infinite sac loops with free or cheap sac outlets.

  • Korvold growth : each loop cycle also pumps Korvold into a flying finisher.
  • Combo wins : Gravecrawler + Pitiless Plunderer + outlet = infinite mana + drain.
