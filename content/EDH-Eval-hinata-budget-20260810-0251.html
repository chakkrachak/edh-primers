1. Commander Sheet

Hinata, Dawn-Crowned

Quick read

  • Core mechanic : every spell you cast costs {1} less per target — Hinata turns multi-target spells into budget bombs.
  • Engine : cast 36 instants/sorceries with token-makers (Young Pyromancer, Talrand, Murmuring Mystic, Deekah) and draw engines (Whirlwind of Thought) converting each spell into value.
  • Payoff : Guttersnipe and Zaffai ping the table with every spell; Metallurgic Summonings and Sunbird's Invocation add free spells.
  • Token swarm : Talrand/Young Pyromancer/Murmuring Mystic + Launch the Fleet / Smoke Spirits' Aid make a wide flying board.

🎯 Control — 285 decks

📖 Game plan

  • Core mechanic : Hinata taxes opponents' spells ({1} more per target) while your own counters are discounted.
  • Answers : Rewind, Unwind, Negate, Neutralize, Saw It Coming, You Find the Villains' Lair counter everything; Generous Gift, Crush Contraband, Return to Dust remove permanents.
  • Engine : draw (Opportunity, Compulsive Research) keeps the answers coming; tokens chump-block.

🏆 Win conditions

  • Value win : out-grind the table with card advantage, then finish with a big X-spell.
  • Dismiss into Dream lock : any targeted removal becomes board destruction.
